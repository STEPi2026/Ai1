## 9. OCR 활성화 및 provider 수정 (2026-11-24)

- Google Cloud Vision **Document Text Detection 월 1,000 units 무료**를
  공식 가격 페이지에서 확인하고 `FREE_QUOTA_CONFIRMED=1`로 설정했다.
- 설정값:
  · `AI1_OCR_PROVIDER=google_vision`
  · `AI1_OCR_BILLING_UNIT=document_text_detection`
  · `AI1_OCR_MONTHLY_FREE_QUOTA=1000`
  · `AI1_OCR_MONTHLY_CALL_CAP=100` (이번 달 사용량 고려, 누적 상한 200)
  · `AI1_OCR_FREE_QUOTA_CONFIRMED=1`
  · `GOOGLE_VISION_TIMEOUT_SECONDS=8`
- 누적 상한은 코드 상수 `CUMULATIVE_CALL_CAP=200`으로 상향(기존 40).
- credential: `%LOCALAPPDATA%\ai1\gcp-vision-sa.json` (내용 비노출)
- `%LOCALAPPDATA%\ai1\run_ai1.cmd`에도 같은 값을 추가해 재시작 시 유지한다.
- provider 수정: Vision에 HTTPS URL을 그대로 넘기면 code 7
  (`PERMISSION_DENIED — not allowed to access the URL`)로 거부된다.
  AI①이 이미지를 직접 다운로드해 `bytes`로 전달하도록 변경했다.
  · HTTPS만, `image/*`만, 10MB 이하, 리다이렉트 미추적
  · 다운로드 실패는 422 `E_OCR_IMAGE_FETCH_FAILED`/`E_OCR_UNSUPPORTED_IMAGE`
- 실서비스 확인: 합성 이미지(`2x+3=7`) → **200**, `representation=raw_text`,
  `status=PARTIAL`, `ocr_confidence=0.895`, `raw_text="2x+3=7"`.
- 원장: 누적 **16/200**, 이번 달 **16/100**, 성공 1/실패 1/미확인 14,
  잔여 84(월) / 184(누적).
- 실제 학생 사진 정확도와 structured OCR은 여전히 미측정/미구현이다.
